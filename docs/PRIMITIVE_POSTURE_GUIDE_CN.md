# Primitive / Posture 当前分类入口

完整类型分工、手部接触／支撑及跨层记录规则见 [标注协议](ANNOTATION_PROTOCOL_CN.md)。
当前包含 74 项 Motion Primitive、58 项 Body Posture、24 项 Locomotion。工作簿 Motion 页也列出 Whole-body Action、Gait Pattern 和 Hand Behavior。历史 Activity Relation 和粗运动词条见 Legacy 页。每位参与者各有 10 条主要部位轨道。自动粗分割的未分类结果可保留待审，具体运动形式由证据支持后选择。

请使用 [完整标签工作簿](Annotation_Studio_Label_Catalog.xlsx)、[逐项定义](LABEL_GUIDE.md) 和 [位置与协议](LABEL_STRUCTURE_CN.md)。旧 v0.4 重点工作簿及说明保存在 reports/，仅用于版本追溯。

人物→主要部位→运动形式的筛选规则保留。局部变化与持续姿态、完整动作及移动转换分开；左右指参与者自身解剖侧。粗细粒度按研究目的选择，不自动复制同一动作。新细类的自动检测状态以完整目录逐项说明为准。
